# SentrIA logo files

The mark is two half domes. The top dome is the alert. The bottom bowl is the action that closes it, with the check from the Handled button.

| File | Use |
|---|---|
| `sentria-mark-on-dark.svg` | Main mark on ink or dark grounds: lime dome, white bowl, ink check |
| `sentria-mark-on-light.svg` | Main mark on white or light grounds: ink dome, lime bowl, ink check |
| `sentria-mark-small.svg` | Under 24 px (tabs, notifications). No check |
| `sentria-mark-mono-ink.svg`, `sentria-mark-mono-white.svg` | One colour, for print and stamps. The check is cut out |
| `favicon.svg`, `favicon-32.png` | Browser tab |
| `app-icon.svg`, `app-icon-1024.png`, `apple-touch-icon-180.png` | App icon on an ink square, the OS rounds the corners |

Colours: lime `#D6FF3F`, ink `#141414`, white `#FFFFFF`.

These files are not wired into the app yet. `public/logo-mark.png` and `public/icon.svg` still hold the old siren.
